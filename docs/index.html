Security Architecture

      
Process and filesystem containment.

      
Operating-system-level guarantees against arbitrary execution or workspace escapes.

    


    

      

        
Win32 Job Objects & Linux cgroups

        
Every spawned shell executes inside an OS job object with memory caps and strict tree termination (JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE). Orphan processes cannot escape.

        Atomic Process Kill Tree
      


      

        
Canonical Path Confinement

        
Filesystem operations resolve through dunce::canonicalize. Any path evaluation attempting to traverse outside the workspace root triggers an immediate error.

        dunce::canonicalize · Zero Symlink Traversal
      


      

        
Interactive Permission Checkpoints

        
Safe read-only commands proceed automatically. File edits, shell executions, and network calls prompt for explicit user confirmation via the TUI.

        Granular Risk Matrix
      


      

        
Local Fallback Gateway

        
The optional local proxy handles multi-model failover strictly on loopback (127.0.0.1) with per-session token validation. Zero telemetry or external beacons.

        Zero Telemetry · 100% Offline Capability
